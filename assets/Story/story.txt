# Grave Reckoning: story pages. Plain text, edit freely.
#
#   page <name> <layout>      layouts: 1 (one panel), 2 (two stacked), 2s (two side by side),
#                             3 (wide on top, two below), 4 (2x2), comic, parchment
#   panel <image>             a PNG in this folder (Panels/...), shown in layout order
#   art <image>               comic layout: the whole comic page, one PNG (Comic/...), 456 px wide
#   beat <x> <y> <w> <h>      comic layout: the strip of the page that one press of A reveals
#                             (tools/slice_comic.py prints these, one per row of panels)
#   caption <text>            narration box in the corner of the last panel (lines join)
#   say <text>                speech balloon at the bottom of the last panel; on a comic page, a
#                             see-through plate over the foot of that beat's strip, shown while it is
#                             the newest strip
#   speaker <NAME>            comic plates: the name above the line (capitals, short)
#   at left|right             comic plates: which side of the strip, nearest the speaker
#
# A reveals the next panel, then the next page. START skips the rest. Pages are
# looked up by name: "intro" before the first grave, "ch1".."ch6" at the start of
# each chapter, "ch1b".."ch5b" at the start of the NEXT chapter, before its own pages (the
# lead-up pages that bridge two chapters), "end".."end4" (with "end2b") and "epilogue" after the last grave.
# Pages with the same name are shown in file order. Keep captions short: no more than
# two or three short lines to a beat; on a comic page the words sit in a band under the art
# (the latest caption and the latest spoken line seen so far).
